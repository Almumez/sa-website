# بوابة الملفات

بوابة عربية لإدارة الوثائق والملفات، مجهزة للنشر على Vercel باستخدام Next.js وTurso وتخزين خاص متوافق مع S3، مثل Cloudflare R2.

- حساب مدير وحسابات أعضاء بصلاحيات مستقلة للإضافة والتعديل والحذف.
- رفع ملفات حتى 20 MB مباشرة إلى التخزين، والتحقق منها في الخادم قبل حفظها.
- روابط عرض وتنزيل عامة، وروابط مخصصة تبقى أسماؤها السابقة صالحة.
- عارض PDF وصور، ومحرر صفحات PDF يعمل داخل المتصفح.
- تعديل البيانات واستبدال الملفات والحذف القابل للاستعادة وإعداد الاسم والشعار.

## التشغيل والنشر

المتطلب: Node.js 22.13 أو أحدث. انسخ `.env.example` إلى `.env.local` وأدخل قيم خدماتك.

```powershell
npm ci
npm run db:migrate
npm run dev
```

أمر الهجرات لقاعدة جديدة، وليس لاستيراد قاعدة Cloudflare قديمة بلا مراجعة. التفاصيل الكاملة في [دليل النشر](DEPLOYMENT.md)، وتشمل متغيرات البيئة، وCORS، وإعداد المدير، والحفاظ على البيانات القديمة.

```powershell
npm run typecheck
npm run build
npm run test:vercel
```

الاختبار يشغّل نسخة الإنتاج باستخدام قاعدة مؤقتة وخادم تخزين محاكى، ولا يستخدم قاعدة الإنتاج.

## البيانات وحجم المشروع

بيانات النسخة المحلية القديمة محفوظة في `.wrangler/state/v3`، ولم تنقلها هذه التعديلات. قاعدة Turso الجديدة تبدأ فارغة حتى نقل البيانات. لا تحذف مجلد `.wrangler` قبل النسخ الاحتياطي والنقل.

مجلدات `.sites-runtime` و`node_modules` و`dist` و`.next` ملفات تشغيل أو حزم أو بناء، وتستبعد من نسخة الرفع. لإنشاء أرشيف مصدر خفيف دون بياناتك أو أسرارك:

```powershell
python scripts/package-vercel.py
```

ينتج `outputs/files-portal-vercel.zip`. تعليمات وميزات نسخة Cloudflare السابقة محفوظة للرجوع في [التوثيق القديم](docs/legacy-cloudflare.md)، ولا تعد تعليمات النشر الحالية.
