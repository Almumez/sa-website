# بوابة الملفات

موقع عربي لإدارة الملفات وعرض الوثائق، مع شريط عرض بألوان وتنسيق مستوحى من الصفحة المرجعية.

- الموقع: `/`، لوحة التحكم: `/admin`، عرض الوثيقة: `/files-portal/<id>`.
- تخزين دائم للبيانات في D1 والملفات في R2؛ لا تعتمد الملفات على تخزين المتصفح.
- تسجيل الدخول عبر ChatGPT. الإدارة محصورة بصاحب الموقع؛ روابط عرض الوثائق وتنزيلها متاحة لأي شخص يحمل الرابط دون تسجيل الدخول.
- رفع PDF والصور PNG/JPEG/WebP وملفات Office الحديثة وTXT وCSV وZIP حتى 20 MB.
- معاينة PDF والصور؛ تنزيل الأنواع الأخرى. تعديل بيانات الوثيقة، بحث وتصفية، وسلة قابلة للاستعادة.
- روابط الوثائق عامة وغير مفهرسة؛ إيقاف الوصول يكون بنقل الوثيقة إلى سلة المحذوفات.

## تشغيل محلي

المتطلبات Node.js 22.13 أو أحدث.

```powershell
npm run install:ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_talented_rawhide_kid.sql
npm run dev -- --port 5185 --hostname 127.0.0.1
```

تطبق الهجرة مرة واحدة لكل قاعدة محلية جديدة. افتح `/signin-with-chatgpt?return_to=/admin` لتسجيل الدخول التجريبي المحلي. المحاكاة محلية فقط؛ المصادقة المنشورة تديرها منصة Sites.

## التحقق

نجح بناء الإنتاج وفحص TypeScript. اختُبرت عبر HTTP: حماية الطلبات غير المسجلة، الرفع والحفظ في D1/R2، تطابق محتوى التنزيل، صفحة العرض، تعديل البيانات، الحذف القابل للاستعادة، الاستعادة، ورفض الكتابة من أصل مختلف. تعذر الفحص البصري بالمتصفح بسبب توقف أداة التحكم؛ مطابقة التصميم اعتمدت على قراءة بنية الصفحة المرجعية وأنماطها.


## إعدادات الاسم والشعار والعارض

افتح `/admin/branding` من رابط «الاسم والشعار» داخل لوحة التحكم. غيّر الاسم، وارفع شعار PNG أو JPEG أو WebP حتى 2 MB، ثم اختر الاسم فقط أو الشعار فقط أو كليهما واحفظ. تُخزن الإعدادات في D1 والشعار في R2 وتطبق على صفحات صاحب الحساب.

صفحة `/files-portal/<id>` لها شريط علوي مستقل بارتفاع 27 بكسل ولا تعرض أي روابط إدارة أو تسجيل دخول وخروج. يطابق ترتيب بياناتها المرجع، ويستخدم تاريخًا ميلاديًا بالأرقام الإنجليزية. صفحات العرض عامة، بينما صفحات الإدارة وقائمة الملفات محمية.

عارض PDF مبني على PDF.js ويعمل محليًا دون إرسال الملف لخدمة خارجية. يعرض الصور المصغرة، والتنقل، والتكبير، وملاءمة العرض، وتدوير جميع الصفحات أو الصفحة المحددة، والوضع الليلي والتنزيل. تُنسخ ملفات PDF.js والخطوط وملفات العامل من الحزمة المثبتة تلقائيًا قبل البناء والتشغيل، مع ترخيصها.


خط بيانات الوثيقة هو Tajawal المستخدم في المرجع، بأوزان 400 للقيم و700 للعناوين. الوضع الليلي يغير إطار العارض وأدواته ويحتفظ بألوان صفحات المستند وصورها المصغرة. الزران الخارجيان يدوران جميع الصفحات والزرّان الأوسطان يدوران الصفحة المحددة. عنوان التبويب يأتي من الاسم المحفوظ في قاعدة البيانات، وتُحدّث الصفحات المفتوحة عبر BroadcastChannel وعند التركيز عليها.


أيقونة التبويب تستخدم الشعار المحفوظ حتى عند اختيار عرض الاسم فقط داخل الشريط. يتغير عنوان رابط الأيقونة بإصدار الحفظ لتحديث ذاكرة المتصفح، وتحدث روابط icon وshortcut icon وapple-touch-icon في الصفحات المفتوحة. رسومات أدوات PDF الأساسية تستخدم مسارات SVG من المرجع المطلوب بدل رسومات Lucide العامة.


## عرض الملفات دون تسجيل دخول

مسار `/files-portal/<id>` وقراءة `/api/documents/<id>` متاحان دون جلسة دخول. يُتاح شعار الوثيقة عبر `/api/branding?document=<id>`، دون كشف هوية صاحب الملف أو مفتاح التخزين. معرفات الملفات UUID عشوائية ولا توجد قائمة ملفات عامة. الوثائق المحذوفة لا تُعرض ولا تُنزّل. صفحات العرض تحمل noindex وnofollow.

الإدارة والرفع والتعديل والإعدادات مقيدة بحساب صاحب الموقع، وفق عنوانه الموثق في رؤوس مصادقة Sites ومطابقته لمتغير الخادم السري `SITE_OWNER_EMAIL`. غياب هذا المتغير يمنع الإدارة. قائمة الملفات والتعديل تظل مقيدة كذلك بمعرّف صاحب السجل. يضبط هذا المتغير على عنوان حساب المعاينة في `.dev.vars` محليًا فقط؛ الملف مستبعد من المصدر وحزمة النشر.
