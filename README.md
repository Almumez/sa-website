# بوابة الملفات — تخزين JSON

بوابة عربية لإدارة الوثائق والحسابات والصلاحيات وعرض وتحرير PDF. محليًا يحفظ البيانات والملفات في مجلد المشروع؛ على Vercel يستخدم R2 للحالة JSON والملفات عند ضبطه، مع ترحيل آمن للحالة القديمة من Vercel Blob ودون قاعدة بيانات SQL.

## مكان البيانات

```text
data/
  portal.json                 # الجداول والحقول والحسابات والروابط والجلسات
  portal.previous.json        # نسخة JSON السابقة قبل آخر تغيير
  migration-manifest.json     # تقرير تحقق النقل من النسخة القديمة، إن تم النقل
  uploads/                    # الملفات والشعارات بأسماء مشتقة من مفاتيحها
```

الجداول ممثلة بمصفوفات داخل JSON واحد حتى يكون حفظ التغييرات المترابطة ذريًا. ملفات PDF والصور لا تخزن بصيغة Base64 داخل JSON. كلمات المرور تبقى مشتقة باستخدام PBKDF2، ورموز الجلسات محفوظة كبصمات فقط. مجلد البيانات خاص، خارج `public` ومستبعد من Git وأرشيف المصدر.

## التشغيل

المتطلب: Node.js 22.13 أو أحدث. في هذا المشروع نُقلت بيانات النسخة المحلية القديمة إلى مجلد `data` مع بقاء الأصل في `.wrangler` والنسخ الاحتياطية في `backups`.

```powershell
npm ci
npm run dev
```

افتح `http://localhost:3000/login` وسجل ببيانات حسابك السابق. لا تنشئ المدير من جديد بعد نقل الحسابات.

لمخزن جديد فقط، انسخ `.env.example` إلى `.env.local`، وضع `SITE_OWNER_EMAIL` ومفتاح إعداد عشوائي لا يقل عن 32 حرفًا في `ADMIN_SETUP_SECRET`، ثم افتح `/setup`. لا توجد كلمة مرور افتراضية.

```powershell
npm run build
npm test
npm start
```

اختبارات الإنتاج تستخدم بيانات مؤقتة ولا تعدل مجلد `data` الحقيقي. راجع [دليل التشغيل والنشر](DEPLOYMENT.md) للنسخ الاحتياطية ونقل البيانات وإعداد الخادم.

## الاستضافة

على Vercel أعد Cloudflare R2 كما في [دليل التشغيل والنشر](DEPLOYMENT.md) لتفعيل الحالة والملفات الدائمة. يقرأ التطبيق حالة Blob القديمة تلقائيًا وينقلها إلى R2 عند أول تعديل دون حذف النسخة القديمة. إذا لم تضبط R2، يمكن استخدام Vercel Blob كمسار احتياطي.

للاستضافة على خادم Node.js بقرص دائم، يمكن تشغيل الوضع المحلي بمجلد `data/`. قفل الكتابة يدعم عدة عمليات Node على الجهاز نفسه، وليس عدة خوادم أو أقراص شبكة.

[التوثيق القديم](docs/legacy-cloudflare.md) مرجع لنسخة Cloudflare السابقة، وليس تعليمات التشغيل الحالية.
